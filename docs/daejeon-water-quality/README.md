# 카피바라 대전 하천 탐험

`카피바라_대전_하천탐험.html`을 Chrome 또는 Edge에서 열면 실행됩니다. 인터넷 연결은 필요하지 않습니다.

- WASD / 방향키: 이동, Shift: 달리기, E: 가까운 표지판 관찰, Esc: 닫기
- 빈 맵에서 마우스 좌클릭을 누른 채 드래그: 카메라 좌우 회전·위아래 기울기 조절. 이동키는 현재 카메라 방향을 따릅니다. 학교로 버튼으로 시점도 초기화됩니다.
- 마우스 휠 위로: 확대, 아래로: 축소. 카메라 거리는 65~230맵 단위로 제한합니다. 학교로 버튼으로 줌도 초기화됩니다. 데이터 창 위의 스크롤은 카메라에 영향을 주지 않습니다.
- 왼쪽 지점 목록: 목적지 안내. 순간이동하지 않습니다.
- 학교로: 출발점 복귀
- 대전 명소 찾아가기: 한빛탑·대전컨벤션센터·한밭수목원·대전시청·대전역·대전월드컵경기장 앞 광장 길 안내
- CSV 불러오기: 지점별 데이터 등록
- HTML 저장: 현재 데이터를 포함한 독립 HTML 다운로드

## 나중에 실험 데이터 연결하기

실제 실험값은 넣지 않았습니다. 데이터_양식.csv를 엑셀에서 편집하고 **CSV UTF-8**로 저장해 불러오세요. XLSX 직접 불러오기는 이번 파일에 포함되지 않았습니다.

지점 ID: G1 갑천 엑스포교 일대 / G2 갑천 원촌교 일대 / G3 갑천 만년교 일대 / Y1 유등천 태평교 일대 / D1 대전천 목척교 일대.
이 지점들은 후보 예시입니다. 확정 채수 위치와 이름을 받으면 sites 배열과 지도 위치를 수정해야 합니다. 지도는 실제 좌표를 투영한 GIS가 아닌 대전 하천의 연결 관계를 단순화한 탐험 공간입니다.

CSV 첫 줄의 영문 열 이름을 유지하세요. 지점당 한 행이며 여러 날짜 시계열은 지원하지 않습니다. 불러온 지점은 해당 행의 값으로 교체되며 빈칸은 미등록입니다. 포함되지 않은 지점은 유지됩니다. 숫자 0은 실제 0으로 표시됩니다.

|열|내용|
|---|---|
|id|지점 ID|
|date|채수일 YYYY-MM-DD|
|mp|FT-IR 확인 미세플라스틱 농도, 개/L|
|volume|분석 시료 부피 L|
|polymer|확인된 고분자 종류|
|method|분석 방식과 검출 크기 범위|
|bod / cod / tn / tp|공공 수질 BOD / COD / 총질소 / 총인, mg/L|
|publicDate|공공 수질 측정일|
|source|공공데이터 출처 URL. 대전광역시 내 자료만 입력|
|station|공식 측정소명|
|inhibit|물벼룩 유영저해율 %|
|ros|ROS 값, 단위, 정규화 기준|
|exposure|노출 시간과 시험 조건|
|memo|실제 채수 위치, 반복 측정, 불확도 등|

브라우저 저장은 기기·브라우저별이며 공유 DB가 아닙니다. HTML 저장 버튼으로 결과 파일을 보관하세요. 공공 수질 수치는 자동 수집하지 않습니다. 공공 측정소의 위치와 날짜를 실제 채수 기록과 구분해 등록하세요.

## 주요 장소 배치 기준

학교를 포함한 주요 장소 중심 간 최소 45맵 단위, 일반 건물 중심 간 최소 24맵 단위를 확보합니다. 각 주요 장소의 반경에 추가 14맵 단위를 더한 영역에는 일반 건물과 무작위 나무를 생성하지 않습니다. 실제 미터 축척은 없으며, 하천 기준 동서·남북 관계를 유지한 개략 배치입니다.

한빛탑(고리 전망대), DCC(넓은 전시장 지붕), 한밭수목원(산책로·나무·온실), 시청(층이 쌓인 청사), 대전역(역사·선로), 월드컵경기장(운동장·관람석)을 서로 구별되는 단순 모형으로 표현했습니다. 상세 실측 건축 모형은 아닙니다.

## 이번 파일에 수록한 공식 공공 수질

대전광역시 보건환경연구원 환경조사과의 **2026년 8월 3대 하천 수질현황**을 수록했습니다. 채수일 2026-08-11, 게시일 2026-09-02, 확인일 2026-09-08입니다.

- 갑천 6곳, 대전천 4곳, 유등천 6곳: 총 16개 공식 측정소
- 기본 항목: BOD, COD, T-N, T-P
- 추가 항목: 수온, pH, DO, SS, 전기전도도, TOC, DTN, NO3-N, NH3-N, DTP, PO4-P, Chl-a, 총대장균군, 분원성 대장균군, 페놀류
- 불검출은 원자료 표기를 유지하며 0으로 치환하지 않습니다.
- ‘공공 수질 → 공식 공개자료’에서 같은 하천의 측정소를 고릅니다. 표지판 위치와 공식 측정소는 다를 수 있으므로 현재 표지판 자리에서 측정한 값으로 간주하지 않습니다.
- ‘직접 등록한 자료’에서는 기존 CSV/입력폼으로 저장한 수질값을 확인할 수 있습니다. 공식 수록값은 별도로 유지됩니다.
- 파일에 저장된 단일 날짜의 공개자료입니다. 실시간 조회 또는 자동 업데이트가 아닙니다.
