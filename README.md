# 카피바라 환경동아리 메타버스

대전과학고등학교 환경동아리 "카피바라"가 만드는 HTML 기반 메타버스입니다.
각 HTML 파일을 더블클릭해서 바로 브라우저에서 열 수 있습니다 (별도 서버 불필요).

## 구성

- **`start-map.html`** — 시작맵. Three.js 저폴리 3D 공간에서 카피바라 캐릭터를 조작해
  걸어다니며, 포탈을 통해 다른 관(이론관/대전지도관/실험실관/캠페인관)으로 이동하는
  구조의 출발점입니다.
- **`campaign-hall.html`** — 캠페인관 로비. 같은 3D 엔진으로 만든 광장에 부스 5개가
  배치되어 있고, 각 부스에 다가가 Enter를 누르면 미니게임이 오버레이로 열립니다.
- **`daejeon-hall.html`** — 대전지도관. 갑천·유등천·대전천의 채수 후보 지점 5곳을
  3D로 탐험하며, 표지판마다 미세플라스틱(동아리 실험값)·공공 수질(대전시 공식
  자료, 내장됨)·생태독성 탭을 확인하고 직접 측정값을 입력/CSV로 불러올 수
  있습니다. `docs/daejeon-water-quality/`에 원본 PDF·공식 CSV·입력용 CSV
  양식·상세 설명이 들어있습니다 (앱 자체는 이 폴더 없이도 완전히 동작합니다).
- **`games/`** — 캠페인관의 미니게임 모듈 5종 + 공용 오버레이 엔진.
  - `game-core.js` — 모든 게임이 공유하는 오버레이(시작 화면/결과 화면/일시정지),
    최고점 저장, 효과음(WebAudio) 등 공용 기능.
  - `game-lc50.js` — LC50 푸시 유어 럭 (용량-반응 추정 게임)
  - `game-mastermind.js` — 오염 마스터마인드 (추리 게임)
  - `game-suika.js` — 재활용 수박게임 (Matter.js 물리엔진 기반 합치기 게임)
  - `game-daphnia.js` — 물벼룩 서바이벌 (생존 액션)
  - `game-defense.js` — 트로이 목마 디펜스 (타워 디펜스)
- **`data/config-data.js`** — 위 모든 게임의 수치/확률/텍스트가 모여있는 설정 파일.
  밸런스 조정이나 실제 실험 데이터로 교체할 때 이 파일만 수정하면 됩니다.

## 기술 스택

- Three.js (CDN, ES Module import map)
- Matter.js (CDN, 수박게임 물리엔진)
- 순수 HTML/CSS/JavaScript, 외부 빌드 도구 없음
- 효과음은 전부 WebAudio로 즉석 합성 (외부 음원 파일 없음)

## 참고

게임 속 실험 수치(LC50, ROS 등)는 전부 가상 데이터입니다. 실제 실험 결과는
동아리 부스에서 별도로 확인할 수 있습니다.
